# 16bit 数据类型与 March C

配置字节 3 的 `din_sel` 使用以下定义。测试模式字节 2 仍为 0=只写、1=只读、2=写读。
本表针对 x16 芯片；x8 芯片保留原定义。随机模式仍采用 TRNG 种子加可重放 PRNG。

| din_sel | 只写 / 只读 | 写读（一轮） |
| --- | --- | --- |
| 1 | 全 0000，只操作一遍 | 写全 0000 → 读验全 0000 → 写全 FFFF → 读验全 FFFF |
| 2 | 全 FFFF，只操作一遍 | 写全 FFFF → 读验全 FFFF → 写全 0000 → 读验全 0000 |
| 3 | 5555、AAAA，相邻地址交替 | 同左，写完全区再读验全区 |
| 4 | AAAA、5555，相邻地址交替 | 同左 |
| 5 | 0000、FFFF，相邻地址交替 | 同左 |
| 6 | FFFF、0000，相邻地址交替 | 同左 |
| 7 | 0000、0001、0002… | 同左 |
| 8 | FFFF、FFFE、FFFD… | 同左 |
| 9 | 随机数 | 同一轮种子生成写值并重放读期望值 |
| 10 | March C，执行完整算法 | 不支持 |

模式 3–8 每轮从首值开始；写读的读验阶段恢复同一序列。递增/递减以相对地址偏移
为准，16 位回绕；并非从绝对地址取值。模式 1/2 的一次循环包含两组背景数据，
只发送一份整轮汇总，循环号不会因内部阶段增加。

## March C：11N

0、1 分别表示 0000、FFFF，r 表示读验，w 表示写入。N 为配置的地址数量：

1. 升序对全区 w0。
2. 升序，每个地址先 r0，再对同一地址 w1。
3. 升序，每个地址先 r1，再对同一地址 w0。
4. 升序对全区 r0。
5. 降序，每个地址先 r0，再对同一地址 w1。
6. 降序，每个地址先 r1，再对同一地址 w0。
7. 升序对全区 r0。

共 5N 次写入、6N 次读验。模式字节为“只写”或“只读”时，选择 10 都执行完整
March C；因此该选择包含写入操作。每个读写对必须在同一地址完成后才移动地址。

复用现有 5 ns 引脚引擎及 IOB 捕获。读验后先排空实际采样、比较和错误入队流水，
然后才使能 FPGA 写驱动；方向切换存在空闲间隔，实际耗时包含这些间隔，不等于
11N 乘以配置周期。全区连续读阶段不会因错误或 FIFO 满而暂停。

## 错误统计和上位机

普通只写/只读仍使用 11 字节报告；写读和 March C 使用现有 17 字节汇总，
开启详细日志时使用现有 25 字节明细。March C 是新增类型，上位机应对 10+模式 0/1
按 17/25 字节报告解析，不能沿用只写/只读的 11 字节预期。

整轮所有阶段累计错误，阶段切换不清空 FIFO 或计数器。March C 可在同一地址的
多个阶段重复报错，错误总数可能大于 N；长度字段仍表示地址数 N。明细携带地址、
实际值、期望值与整轮错误序号，不增加阶段字段。FIFO 仍为 4096 条，满后继续测试、
计入全部错误并丢弃新明细。只有整轮所有操作完成且缓存明细排空后才上报汇总；
汇总 ACK 后才进入下一轮。

10+模式 2 或 x8+10 在校验配置时被拒绝：不更新生效配置、不启动测试，也不新增
错误回复帧。上位机应禁止选择这些组合。

读采样、升降序和同地址读写对。验证单地址、奇数长度、多轮、同模式重启、

以及 401740 拍独立的算法引脚时序检查，包含未上报旧错误时替换正在运行的 March C。
普通随机/固定序列回放通过 76 组用例、277749 次写入；原有 142 组引脚配置、
854920 个谓词边界、10 份完整普通报告、518 次 SPI 轮询、详细日志和种子专项
也通过。时序收集 Tcl 用替代命令检查了流程，未运行 Vivado。

模型使用理想时钟、35 ns 地址到数据延迟和显式的 10 ns 输出关闭保持假设，
不证明真实器件的采样窗口、板级信号或布局时序。当前引脚时序规则保持原约定：
Read1 实际采样 40 ns、Read2 实际采样 45 ns；Read2 最低周期 40 ns。
