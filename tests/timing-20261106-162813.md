## 修改

- 用 P-2 事件预测并寄存 P-1，同拍更新数据、随机状态与周期事件；保留原比较供仿真对照。
  支持范围仍为 P>=7，未移动数据或控制引脚边沿。
- 预测下一拍采样倒计时是否仍有剩余，冲刷、暂停、新读启动与元数据状态同时更新。
  寄存值每拍对应原 `valid && delay>2`，切断倒计时到输出命令的组合长路径。
- 计数在 P-2 更新，终值判断提前寄存，在周期边界消费；首周期仍走启动事件。
- 用写转读条件预测 rd_en 上升沿，读重放脉冲与原 `rd_en && !rd_en_d` 同拍。
- SPI 汇总先寄存就绪状态，宽 TX 缓冲不再直接受 test_busy 长组合链控制。
  保留当前错误/FIFO 非空的即时拦截，报告格式及 ACK 语义不变。
- 异步复位仅接板级 rst_n。配置 CRC 提交时同步取消旧引擎、读元数据和重放事件，
  新命令仍由原启动流水开始；移除 TMODE_D1/D2 的差分复位，消除其 recovery 路径。

滚动规则、单遍流程、40/45 ns 实际采样、75 个 IOB、4096 条 FIFO 保持原定义。
没有修改时钟或增加 false path / multicycle path，未恢复 ILA。

## 验证及本机复测

独立引脚回归逐拍比较预测值和原组合判断，覆盖三写、两读、首地址、多轮、同一板级复位下的跨模式命令。
数据回归新增所有类型的 A/CE/WE/OE/UB/LB 逐拍检查，相位由配置长度和经过时钟独立推导。
3–6 交替类型均覆盖三写、两读、长度 1/5、两轮；保留 65537 字三轮滚动、完整读回和同模式重启。
SPI 回归覆盖明细、缓存溢出、完整汇总和重试。

云端无 Vivado，本修改尚无新的布局布线结果。同步后 Reset synth_2，重新综合、实现，
用 `tests/collect_spi_timing.tcl` 收集报告；新增预测/缓存 FF 签名和旧模式复位 FF 数（预期 0）。
setup/hold 是否满足须由新报告确认。时序通过后再对照 3–6 的板上控制和 DQ 波形。
